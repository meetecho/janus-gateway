Plugin Demo: Media Over QUIC (MoQ)

Want to learn more about the MoQ plugin? Check the Documentation.

Demo details

This demo is a basic demonstration of how a gatewaying between the WebRTC and MoQ protocols could look like, with respect to audio and video streams. It allows you to either publish, or subscribe to, MoQ tracks using WebRTC via Janus. The MoQ plugin performs the gatewaying to/from MoQ using the imquic library. This can be tested against the LOC demos in the imquic repo.

Note well! Please notice that the whole MoQ spec is currently being defined, meaning many things will probably change before it can be considered stable. As such, this plugin is currently a work in progress, and so everything you test here should be considered very experimental.
